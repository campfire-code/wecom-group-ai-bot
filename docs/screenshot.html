企微群 AI 答疑机器人

在企业微信群里 @机器人 提问，机器人先到你放好的 Markdown 知识库里检索，再调用大模型按资料作答；资料里没有就按固定话术回复，不乱编。

怎么用

  1. 准备能被企业微信访问到的公网服务器，装好 Docker
  2. 下载 docker-compose.yml 和 .env.example，改名为 .env 并填写回调 Token、EncodingAESKey 和大模型接口
  3. 把知识库 .md 文件放进 kb 目录，运行 docker compose up -d
  4. 访问 /healthz 返回 ok 后，在企业微信机器人配置页保存回调地址，群里 @机器人 提问
交付形式　Docker 部署（docker-compose.yml + .env），命令行，没有图形界面
